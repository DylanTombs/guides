# 5 free things for your startup

From YC, Anthropic and Harvard. All free. The cloud credits need an application, and Startup School needs you to request a spot.

[Open the web version](https://dylantombs.github.io/guides/startup/)

1. **[Startup School Europe](https://events.ycombinator.com/startup-school-europe-2027)** (Y Combinator, London, 6 February 2027)
   A day of talks and sessions with YC partners. Paul Graham and Garry Tan are on the speaker list. You don't need a startup yet, just apply for a spot early.
2. **[Mastering Claude Code in 30 minutes](https://www.youtube.com/watch?v=6eBSHbLKuN0)** (Boris Cherny, Anthropic)
   The person who created Claude Code shows the shortcuts and workflows he uses. Free on YouTube.
3. **[gstack](https://github.com/garrytan/gstack)** (Garry Tan, President & CEO of YC)
   His open source Claude Code setup. It turns one agent into a team: CEO, eng manager, designer, reviewer, QA and release engineer. MIT licence.
4. **[Startup Secrets](https://cosmolearning.org/courses/startup-secrets-with-michael-skok-at-harvard-i-lab/video-lectures)** (Michael Skok, Harvard Innovation Labs)
   The i-lab's lecture series on building a startup, from pitching to competitive advantage.
5. **Free cloud credits**
   - [Google for Startups](https://cloud.google.com/startup): up to $350,000 in Google Cloud credits.
   - [AWS Activate](https://aws.amazon.com/startups/credits): up to $200,000 in AWS credits.
